# 소리수첩

스마트폰 브라우저에서 바로 쓰는 음성 메모장입니다. 설치 없이 열 수 있고, 홈 화면에 추가하면 앱처럼 쓸 수 있습니다.

## 기능

- 버튼 하나로 녹음, 일시정지, 취소. 멈추면 자동 저장
- 녹음 중 실시간 파형과 경과 시간 표시, 화면 꺼짐 방지
- 녹음하면서 한국어 받아쓰기 (음성 인식을 지원하는 Chrome·Edge·Safari 등)
- 저장된 녹음이나 가져온 오디오 파일을 텍스트로 변환 (Whisper 모델이 휴대폰 안에서 실행되어 음성이 밖으로 나가지 않음)
- 메모마다 제목과 본문 편집, 제목·내용 검색
- 재생 속도(0.75×~2×), 15초 앞뒤 이동
- 공유(메신저 등으로 오디오 파일 전송), 파일로 저장, 삭제
- 녹음 파일은 기기 안(IndexedDB)에만 저장되고 서버로 전송되지 않음
- 오프라인에서도 열림 (서비스 워커)

## 실행

마이크는 HTTPS 또는 localhost에서만 동작합니다.

**GitHub Pages로 배포 (권장)**
1. 저장소 Settings → Pages
2. Source: `Deploy from a branch`, Branch: `main` / `/ (root)` 저장
3. 휴대폰에서 `https://dddwin72.github.io/memory1/` 열기
4. 브라우저 메뉴에서 "홈 화면에 추가"

**로컬 테스트**
```
python3 -m http.server 8000
```
실행 후 `http://localhost:8000` 접속.

## 참고

- 받아쓰기는 브라우저의 음성 인식 서비스를 쓰므로 인터넷 연결이 필요합니다. 일부 안드로이드 기기에서는 녹음과 받아쓰기를 함께 쓰면 받아쓰기가 멈출 수 있습니다. 그럴 때는 녹음 버튼 아래 체크박스로 받아쓰기를 끄세요.
- 텍스트 변환은 처음 한 번 모델을 내려받습니다("빠르게" 약 80MB, "정확하게" 약 250MB). 이후에는 인터넷 없이도 됩니다. Wi‑Fi에서 처음 실행하길 권장합니다. 녹음 1분당 수십 초 정도 걸리며 기기 성능에 따라 다릅니다.
- 브라우저의 사이트 데이터를 지우면 녹음도 함께 지워집니다. 중요한 녹음은 "파일로 저장"이나 "공유"로 백업하세요.
