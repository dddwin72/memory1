# 소리수첩

스마트폰 브라우저에서 바로 쓰는 음성 메모장입니다. 설치 없이 열 수 있고, 홈 화면에 추가하면 앱처럼 쓸 수 있습니다.

## 기능

- 버튼 하나로 녹음, 일시정지, 취소. 멈추면 자동 저장
- 녹음 중 실시간 파형과 경과 시간 표시, 화면 꺼짐 방지
- 녹음하면서 한국어 받아쓰기 (음성 인식을 지원하는 Chrome·Edge·Safari 등)
- 저장된 녹음이나 가져온 오디오 파일을 텍스트로 변환 (Whisper 모델이 휴대폰 안에서 실행되어 음성이 밖으로 나가지 않음)
- 메모마다 제목과 본문 편집, 제목·내용 검색
- 재생 속도(0.75×~2×), 15초 앞뒤 이동
- 공유(메신저 등으로 오디오 파일 전송), 파일로 저장, 삭제
- 녹음 파일은 기기 안(IndexedDB)에만 저장되고 서버로 전송되지 않음
- 오프라인에서도 열림 (서비스 워커)

## 실행

마이크는 HTTPS 또는 localhost에서만 동작합니다.

**GitHub Pages로 배포 (권장)**
1. 저장소 Settings → Pages
2. Source: `Deploy from a branch`, Branch: `main` / `/ (root)` 저장
3. 휴대폰에서 `https://dddwin72.github.io/memory1/` 열기
4. 브라우저 메뉴에서 "홈 화면에 추가"

**로컬 테스트**
```
python3 -m http.server 8000
```
실행 후 `http://localhost:8000` 접속.

## 참고

- 받아쓰기는 브라우저의 음성 인식 서비스를 쓰므로 인터넷 연결이 필요합니다. 일부 안드로이드 기기에서는 녹음과 받아쓰기를 함께 쓰면 받아쓰기가 멈출 수 있습니다. 그럴 때는 녹음 버튼 아래 체크박스로 받아쓰기를 끄세요.
- 텍스트 변환은 처음 한 번 모델을 내려받습니다("빠르게" 약 80MB, "정확하게" 약 250MB). 이후에는 인터넷 없이도 됩니다. Wi‑Fi에서 처음 실행하길 권장합니다. 녹음 1분당 수십 초 정도 걸리며 기기 성능에 따라 다릅니다.
- 브라우저의 사이트 데이터를 지우면 녹음도 함께 지워집니다. 중요한 녹음은 "파일로 저장"이나 "공유"로 백업하세요.

# 스트레스 TV 참교육 라이브 (`stress-tv/`)

나를 힘들게 한 사람의 이름과 얼굴 사진을 넣으면 그 얼굴을 한 상대가 링에 오르는 스트레스 해소 게임입니다. Three.js(WebGL)로 만들었습니다. 경기장은 코드로 생성한 3D 모델이고, 주인공·상대·관객은 실사형 3D 사람 모델입니다.

- 조작: `J` 잽, `K` 훅, `L` 어퍼컷, `I` 발차기(앞차기와 돌려차기가 번갈아 나감, 가드 파괴), `SPACE` 회피, `E` 아이템 줍기, `P` 일시정지. 한글 입력 상태에서도 동작합니다. 휴대폰에서는 화면 버튼, 탭(펀치), 위로 쓸기(어퍼컷), 아래로 쓸기(발차기), 옆으로 쓸기(회피)로 조작합니다.
- 손맛 효과(히트스톱, 화면 흔들림, 진동, 의성어), 콤보 배수(최대 ×5), 아이템 5종(뿅망치, 황금 글러브, 바나나 껍질, 고무닭, 슬로모 시계), 피버 모드, 아슬 보너스(반격 직전 회피, 종료 5초 전 버저비터 KO)
- 난이도(지옥): 라운드당 40초, 상대 체력은 라운드마다 증가(340→740). 공격을 멈추면 상대가 체력을 회복하고, 같은 공격 3연타는 읽혀서 빗나가며, 가드에 막히면 콤보가 끊깁니다(어퍼컷·발차기로 가드 파괴). 가짜 공격, 연속 공격, 체력 30% 이하 분노 모드가 있고, 반격에 맞으면 하트를 잃고 상대가 체력을 5% 회복합니다. 하트는 S등급으로 이겨야만 1개 회복됩니다. 수치는 `index.html`의 `DIFF` 한 곳에서 조정합니다.
- 주인공과 상대: 실사형 3D 사람 모델(남자·여자)을 시작 화면에서 각각 고릅니다. 올린 사진은 상대 얼굴에 입혀지고(남자 모델은 얼굴 굴곡을 따라, 여자 모델은 얼굴 앞 패치로), 목과 손의 피부색도 사진에 맞춥니다. 미리보기의 점선(눈·입)에 사진을 맞추면 눈·코·입이 모델 얼굴과 겹칩니다. 사진이 없으면 모델의 원래 얼굴로 싸웁니다. 주먹과 발이 상대의 머리·몸통에 실제로 닿도록 공격마다 높이와 돌진 거리를 맞추고(상대가 떠 있으면 높이를 따라가고, 바나나에 미끄러져 쓰러지면 다가가서 밟습니다), 혹·반창고·튀어나오는 눈알·수건 같은 개그 소품은 실제 머리 위치에 붙습니다. 모델을 불러오지 못하면(파일을 직접 연 경우 등) 코드로 만든 만화풍 캐릭터로 자동 전환됩니다.
- 관객: 실사형 3D 사람 모델 2종(평상복 남성, 여성)을 불러와 차렷·만세·주먹 흔들기·박수·춤 자세로 미리 구워 둔 뒤 관객마다 골라 씁니다. 남성 관객의 옷 색은 경기장마다 다르게 입히고, 큰 경기장은 PC 120명·휴대폰 56명까지 앞줄부터 채웁니다. 모델을 못 불러오면(예: 파일을 직접 열었을 때) 기존 블록 관객으로 대신합니다.
- 8개 경기장이 라운드마다 바뀝니다: 사각링, 헥사곤 케이지, 학교 교실, 회사 사무실, 헬스클럽, 학교 운동장, 사우나, 거실
- TV 생중계 연출: 카메라 7대 자동 컷 전환(와이드 카메라는 두 선수를 따라 움직임), PIP 화면, 자막 해설, KO 장면 슬로 리플레이, 과장된 승리 세리머니. 밝은 실내 경기장은 피버·세리머니 때 실내등을 낮추고 파티 조명을 켭니다.
- AI 캐리커처 얼굴: 시작 화면의 "AI 캐리커처 얼굴 만들기"에서 본인 API 키(Google Gemini `gemini-2.5-flash-image` 또는 OpenAI `gpt-image-1`, 모델 이름은 바꿀 수 있음)로 사진 속 인물을 닮은 캐리커처 얼굴을 새로 그려 씁니다. 브라우저가 해당 AI 서비스에 직접 요청하므로 GitHub Pages나 내려받은 파일에서 동작하고, claude.ai 안에서는 보안 정책상 막힙니다. 키 없이 쓰려면 "프롬프트 복사"로 Gemini·ChatGPT 앱에서 이미지를 만든 뒤 "AI 결과 이미지 올리기"로 넣으면 됩니다.
- 사진은 브라우저 안에서만 쓰이고, "AI로 캐리커처 얼굴 만들기"를 누를 때만 선택한 AI 서비스로 전송됩니다. API 키는 "기억하기"를 켰을 때만 이 브라우저의 localStorage에 저장됩니다.

GitHub Pages에서는 `https://dddwin72.github.io/memory1/stress-tv/` 로 열 수 있습니다.

## 사람 모델 출처

`stress-tv/models/`의 두 모델(glTF, 바이너리를 JSON 안에 넣은 형식)은 three.js 예제 저장소(MIT)에서 가져왔습니다.

- `crowd-man.json`: three.js `examples/models/gltf/readyplayer.me.glb` (Ready Player Me 아바타)
- `crowd-woman.json`: three.js `examples/models/gltf/Michelle.glb` (Mixamo 캐릭터)

캐릭터 자체의 권리는 각각 Ready Player Me와 Adobe Mixamo 약관을 따릅니다. 개인적으로 쓰는 데는 문제가 없지만, 상업적으로 배포하려면 각 약관을 확인하세요. 모델은 `fetch`로 불러오므로 파일을 직접 열지 말고 GitHub Pages나 `python3 -m http.server`로 열어야 실사 선수와 관객이 나옵니다.
