# 드래그 → 구글 → NotebookLM (영어 학습 도우미)

웹사이트나 프로그램을 쓰다가 나오는 영어를 **드래그하면** 바로 구글 검색·번역을 하고,
그 **검색 결과를 NotebookLM 노트북의 소스로** 쌓아 주는 도구입니다.

| 구성 | 어디서 동작 | 하는 일 |
|---|---|---|
| `extension/` 브라우저 확장 프로그램 | 크롬 · 엣지 · 웨일 | 드래그 버튼, 우클릭 메뉴, 검색 결과 → NotebookLM 자동 추가 |
| `windows/DragLearn.ahk` | 윈도우의 모든 프로그램 | 브라우저 밖(PDF, 워드, 설치 화면 등)에서 드래그 버튼, 화면 캡처 → 구글 렌즈 |

## 설치 (Windows, 한 번만)

1. 이 폴더(`drag-to-notebooklm`)를 내려받아 압축을 풉니다.
2. **`install.bat`** 을 더블클릭합니다.
   - 파일을 `%LOCALAPPDATA%\DragLearn` 에 복사하고
   - AutoHotkey v2 가 없으면 설치하고
   - **윈도우를 켤 때마다 자동 실행**되도록 등록합니다.
3. 열리는 크롬 확장 프로그램 화면(`chrome://extensions`)에서
   **개발자 모드 켜기 → 압축해제된 확장 프로그램을 로드합니다 →** 주소창에 `Ctrl+V`(폴더 주소가 이미 복사되어 있음) → **폴더 선택**.
4. (권장) 툴바의 확장 아이콘 → 설정에서 **NotebookLM 노트북 주소**를 넣어 두면 항상 같은 학습 노트북에 쌓입니다.

> 맥/리눅스에서는 3번(확장 프로그램)만 설치하면 브라우저 안에서 모두 쓸 수 있습니다.

## 사용법

### 브라우저에서
- 글을 **드래그**(또는 단어 더블클릭) → 옆에 뜨는 버튼
  - **🔍 검색** : 구글 검색
  - **🌐 번역** : 구글 번역
  - **📒 NotebookLM** : 구글 검색 → 결과 패널이 열림 → `보내기` → NotebookLM 에 소스로 자동 추가
- **이미지**: 우클릭 → `구글 렌즈로 이미지 검색/번역` (이미지를 살짝 끌었다 놓아도 버튼이 뜹니다)
- 우클릭 메뉴에도 같은 기능과 `선택한 글만 NotebookLM으로`, `이 페이지를 NotebookLM으로` 가 있습니다.
- 구글 검색 결과 화면 오른쪽 아래의 **📒 NotebookLM으로 보내기** 버튼은 언제든 쓸 수 있습니다.
- 단축키: `Alt+G` 검색, `Alt+N` 검색 후 NotebookLM

### 다른 프로그램에서 (Windows)
- 글을 드래그하면 마우스 옆에 **[검색] [번역] [NotebookLM]** 버튼이 4초간 나타납니다.
- 단축키: `Ctrl+Alt+G` 검색 · `Ctrl+Alt+T` 번역 · `Ctrl+Alt+N` NotebookLM · `Ctrl+Alt+L` 화면 캡처 → 구글 렌즈
- 작업 표시줄 트레이 아이콘 우클릭으로 켜기/끄기, 종료.

## 알아 둘 점
- NotebookLM 에는 공개 API 가 없어, 확장 프로그램이 NotebookLM 화면에서 `소스 추가 → 복사된 텍스트 / 웹사이트 → 삽입` 을 대신 눌러 줍니다.
  구글이 화면을 바꾸면 자동 추가가 실패할 수 있는데, 그때는 패널의 **복사 버튼**으로 붙여 넣으면 됩니다.
- NotebookLM 홈 화면이 열린 경우 노트북을 하나 열면(또는 새로 만들면) 그때 자동으로 추가됩니다.
- 화면 캡처 이미지는 구글 페이지에서 `Ctrl+V` 로 한 번 붙여 넣어야 합니다.
- 제거: `uninstall.ps1` 실행 + `chrome://extensions` 에서 확장 프로그램 삭제.
